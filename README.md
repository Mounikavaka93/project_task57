# STRYDE

A responsive fitness tracker built with React, Vite, and Tailwind CSS. It covers workouts, a daily dashboard, progress charts, goals, a BMI calculator, nutrition, and a contact form.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Pages

The site is a single scrolling page:

- Home — hero and live training snapshot
- Workouts — cardio, strength, yoga, and HIIT, with session logging
- Nutrition — sample meals and daily macros
- Progress — charts, goals, and the BMI calculator
- Contact — studio details and a validated form
